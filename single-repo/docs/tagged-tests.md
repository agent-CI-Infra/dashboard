# 标签化测试

## 功能

E2E 页的「标签化测试」展示源仓标签化测试框架的冻结目录：

- 每个标签维度有哪些值、各值有多少用例。
- PR / Daily / Release 三个组合分别选取哪些标签值，每个组合选中多少用例。
- 有多少用例任何组合都不会选中，这些用例被哪个标签挡住。

看板只读取 CI 已产出的文件，不运行测试，也不修改源仓策略。

## 使用

- **摘要卡**：目录用例数（UT、ST、E2E 三层目录合并后按用例 ID 去重）、各组合选中数、任一组合覆盖率、从未覆盖数。组合卡片同时给出它最近一次运行各层的通过 / 计划数。
- **每个维度的标签与组合**：
  - 每个维度一组，写明单选或可多选、词表值数、实际使用数和默认值。
  - 每个标签值一行，给出用例数；条形中蓝色是被任一组合选中的用例，黄色是从未覆盖的用例。
  - 每个组合一列：✓ 表示组合选取该值，“不限”表示组合不约束该维度，✗ 表示不选。沿一列往下读就是这个组合：同一维度内多个 ✓ 为“或”，不同维度之间为“且”。
  - 卡片顶部用文字列出各组合规则，规则相同的组合写“与 X 规则相同”；没有运行过的组合写“暂无运行”。
- **从未覆盖的用例**：按挡住它的标签归类计数，例如 `status=external`、`model=real`、`os=macos`。展开可查看具体用例 ID，最多列 300 个。
- **标签组合**：标签完全相同的用例被选中的方式也相同。表中每行是一种组合，给出用例数和各组合是否选中；默认值标签显示为灰色。
- 可多选维度（os、arch）上一个用例可带多个值，各值计数之和会大于总数。多平台用例只要有一个平台实例被选中即算覆盖。

## 数据来源与计算

源仓 CI 把每层的 `.ci-results/<层>/tagged/` 上传到 `ut-results`、`st-results`、`e2e-results` 产物：

- 目录名：每个组合都用层名 `ut` / `st` / `e2e`；属于哪个组合（pr / daily / release）读 `plan.json` 的 `profile` 字段，没有该字段的计划（如临时查询 `query`）不计入。旧规则（`daily-ut` 等目录、计划中没有 `profile`）的产物不再读取；看板自己的记录（`.sync/tagged.json`）按组合与层保存、不含目录名，历史记录沿用，无需改写。
- `catalog.json`：该层收集到的全部用例及其标签。
- `plan.json`：该层实际使用的组合（`profile`）、选择器、执行目标和冻结实例。
- `summary.json`：计划、执行、通过、失败、跳过数。

采集时处理方式：

- 下载结果产物时一并读取这三份文件；原始 ZIP、日志和 sourceHash 不保存。
- 目录压缩为“标签签名 + `[用例 ID, 签名序号, 源文件序号]`”，与最近一次各组合运行的选择器、目标和执行结果一起写入 `.sync/tagged.json`。
- 组合规则只取默认分支或已配置[分支线](branch-lines.md)上的非 PR 运行，按分支分别保存；Release 另外接受版本 tag 运行，归入默认分支。PR 分支可能修改自己的策略，因此不作为组合定义。
- 目录取各分支最新一次运行，同一运行的各层结果可以分批补齐。E2E 页按所选分支线显示；非默认分支线不显示没有运行过的组合。
- 标签词表 `test/support/tagged/schema.json` 按各分支目录修订读取一次，用于补齐省略的默认值、列出未使用的词表值；读取失败时保留上一份词表。

计算与源仓框架一致：

- 缺省维度补默认值；平台标签按执行目标展开为实例，在实例上计算选择器。
- 选择器支持 `and`、`or`、`not` 和括号。展示时把各层选择器展开后合并为规则行，含 `not` 时直接显示选择器原文。
- 每次生成快照都会用同一方法重算目录运行各层的选中数，并与该运行的 `plan.json` 实例数对照；不一致时页面提示“覆盖数字仅供参考”。
- 各组合规则所属修订与目录修订不同时，页面注明两者修订；覆盖一律按同一份目录计算。

## 边界

- 结果产物没有上传标签化文件时，该区域显示“尚未读取到标签化测试目录”。
- 缺少某一层时，页面注明缺少的层，该层用例不计入统计。
- “从未覆盖”指当前目录中现有 PR / Daily / Release 规则都不会选中的用例。没有运行过的组合不参与计算。
- 快照只发布计算结果和未覆盖用例（前 300 个）。完整目录只保存在看板仓的 `.sync/tagged.json`，不随 Pages 部署。

## 验证

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_tagged.py' -v
node .e2e/node_modules/playwright/cli.js test --config test/playwright.config.cjs -g "tagged"
```

单元测试覆盖：

- 产物解析：组合 / 层映射，跳过查询和子计划。
- 默认值补齐、选择器语法与优先级、平台实例展开。
- 各层选择器合并为组合规则。
- 维度计数、覆盖、未覆盖原因和冻结计划对照。
- 组合来源的分支限制，同一运行分批补齐。
- 从同步到快照的完整链路。

浏览器用例检查矩阵、规则文字、未覆盖列表、组合表和窄屏布局。
