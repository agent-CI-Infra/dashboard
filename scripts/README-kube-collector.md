# Local production Kubernetes collection

`collect-production-kube-traces.py` reads the production `digitalmate` alias and tenant `jiuwen` from the management API to identify the current binding population. It fingerprints the first 4096 bytes of each binding's process log and reconciles that fingerprint with the shared Kubernetes workspace mount. Only unambiguous matches are read through `kubectl exec`; fingerprint collisions, unavailable logs and unmatched workspaces are excluded and recorded as incomplete coverage. Historical directories are not automatically included.

The remote reader limits file sizes and paths, does not write to the cluster, and reuses the workspace trace collector's sanitized request and tool-event output. It does not publish prompt text, command arguments, tool results, credentials or raw logs. Matching is based on a unique file prefix, not a verified storage-volume identity; an operator should investigate unexpected changes in coverage. `ADX_TOKEN` is used only for management inventory and matching; `KUBECONFIG` provides Kubernetes access.

`run-local-kube-collector.ps1` decrypts a per-user Windows-protected management token, starts a dedicated verified SSH SOCKS tunnel for GitHub, and runs `publish-local-kube-metrics.py`. Kubernetes and management requests use direct connections; GitHub requests must pass through the dedicated tunnel. Publication refuses to replace the snapshot if fewer than 95% of bindings were read. It rebases before publishing and fails on conflicts rather than force-pushing. Only the dashboard's sanitized JSON is pushed, then Pages deployment is dispatched.

The Windows scheduled task must run as the same logged-in account that protected the token and configured GitHub credentials. It needs the kubeconfig file, Python, kubectl, Git, GitHub CLI, SSH, access to the cluster and the Hong Kong egress host. If the computer is off, signed out or disconnected, collection cannot run until it is available. Preserve the previous dashboard snapshot on failure. Do not place the kubeconfig or token in the repository or public data branch.
